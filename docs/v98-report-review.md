## 根因与改法

v97把完整话术拆成了“示范帧”和“检查帧”，但帧有效性仍依赖 `aiMessage` 字符串。闲聊、暂停、看图都会改写这个字符串，导致讲解帧失效；系统回退读取已经准备好但尚未向孩子展示的检查题。之前的回归只确认“暂停不继续播放”和“标准讲后作答能推进”，没有把两个动作接起来验证。

现在讲解会话绑定知识点及本次补救对象，记录原句位置。临时回应只中断播放，不销毁当前教学内容。恢复后重播当前句；暂停和情绪选择不会因音频结束而自动恢复。切题、切知识点或重新讲解则使旧会话失效，旧音频不能恢复它。

另一处测试盲区是布局：控件的外接矩形在视口内，并不意味着孩子能点到。新增 `elementFromPoint` 命中验证，不再把被滚动区域遮住的按钮当作通过；有意隐藏且已有顶部替代入口的按钮不计为缺陷。

截图复核还发现，4张1元纸币单列排布会挤出平板图示区域。纸币改为成对排列，总金额和换算说明另占整行；不改变纸币数量和教学关系。最窄屏键盘讲解模式收起图下重复追问，将空间留给示范图，原整题仍固定显示。

## 发布后的验收

1. 确认服务器健康版本为v98，不仅看GitHub已更新。
2. 元角分答错后，在老师讲2元时说“我想喝水”，再说“我准备好了”：应回到2元的同一句、同一图，而不是直接跳3元。
3. 老师讲解时点看图、插一句闲聊、连续点帮助：只有最新语音有效；没有语音时手动继续可用。
4. 用真实手机打开键盘，检查讲解按钮、原题和输入入口；模拟视口不能替代系统软键盘与浏览器地址栏测试。
5. 使用真实儿童语音、噪声与弱网记录识别错误和等待时间；随后观察连续学习意愿及隔日变式表现。

整体状态采用“工程门禁 / 服务器部署 / 真人验收”分开汇报，不再把局部测试通过率折算成虚假的全站商业化完成百分比。
