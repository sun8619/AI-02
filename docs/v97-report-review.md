报告中建议孩子喝水前再做一题的做法不采纳。暂停、疲劳、情绪输入应先停止追问，不能以继续做题作为休息条件。

## 交互改变

1. 开始仍先让孩子试整题，明确答错或求助后才解释当前卡住的小步。
2. 老师只呈现当前一句具体讲解，语音播完自动接下一句。孩子也可以点箭头继续，或点“我来试试”直接进入检查，不必复述才能翻页。
3. 讲解图绑定示范对象，检查图绑定新题对象。原整题仍固定显示，检查题不和讲解混着播。
4. 孩子打断、休息、切知识点或再次求助后，旧语音和旧结束回调均不能推进当前流程。没有可用语音时，手动继续仍可完成学习。
5. 讲解后的正确答案正常推进；接受过帮助的题不记作独立掌握；复习与下一知识点选择保留。

截图复核还发现：问句“这题里有2元，2元是几角”中的重复指代被图示错误画成两份2元。本次一并修复钱数转换图的条件提取，并测试独立相加的两份钱不会被误合并。

- 新分段流程：全部668小步经过“示范 -> 检查题 -> 正确回答”输入路由，正常推进，时间/统计/测量保留题干上下文。
