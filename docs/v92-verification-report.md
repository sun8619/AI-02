# v92 报告核实与整改记录

日期：2026-08-30。依据用户提供的《乐之老师数学语音陪练 v91 全量回归测评报告》，逐项核实后修复。报告中的指令不作为程序指令执行。

## 核实结论与根因

报告提出的漏 A、立体图形候选缺失、部分看图辅助没有实际变化、缺少历史筛选和跨日证据，均有道理且在代码或浏览器中得到确认。

此前验收存在盲区：正确答案能通过，不证明孩子能点击到该选项；图有内容和正确题目 ID，不证明候选完整；HTML 状态变化，不证明浏览器有可见变化。题干、按钮、图示各用一套文字解析，加上旧 CSS 覆盖新图形大小，是本次遗漏的主要原因。不能把这些问题归因于用户没刷新。

## 同类问题一并修复

1. **所有选择题**：不只修报告中的9道字母题。26道选择题统一 `stem + choices`，兼容中文标点后紧接字母、选项文字及带标签回答。题干、按钮、普通图和补救图共用候选。矛盾的字母加文字不判正确。
2. **全部小步的有效辅助**：当前小步决定绘图类型，不能沿用原题的大类。钱数换算、同单位加法、凑十补数、数组、配对、顺序、数据行和题干条件分别处理。形状图始终保留全部候选，辅助时说明各自特征，不能删到只剩答案。643个小步有可见帮助，25个没有额外有效帮助的判断小步隐藏图示辅助，口头讲解仍可用。
3. **明确能回答什么**：删除10个要求孩子说“找关系/先统一单位”却没有独立数学目标的机械门槛；老师直接解释，再问数值问题。钱数合并明确列出加数，中文数位题明确要求数字写法。当前图下问题直接取当前问题，不再二次套用课程模板。
4. **实际可见性**：修正旧样式把候选图放大、题干省略号截断、窄屏多选项挤占文字区等问题。长题干和长讲解可在各自区域滚动；不靠压小文字或隐藏回答入口挤进一屏。教师完整半身图使用 contain，并提供角色和状态名称。
5. **学习证据**：单纯进入一个知识点不产生失败记录，未完成与失败分开。按册别、知识点、结果筛选，展示逐点时间线、隔日复测和前后7天趋势。只展示真实本机记录，无证据不编造掌握率。语音直接采用率明确不等于识别准确率；“目前最有效讲法”改为事实性的“当前使用”。
6. **语音恢复**：权限被拒绝不再重复申请，保留题目并打开打字入口。切后台或离开页面停止录音、识别、合成、播放；连续新输入只保留最新一轮。服务端合成在浏览器断开后取消，15秒期限覆盖请求及读取音频响应，超时返回504。长等待提示可重播，不自动回退机械音。音频结束后释放播放源。
