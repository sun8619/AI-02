# 乐之老师小台阶讲解规范与来源

## 目标

孩子答错当前小台阶后，系统不直接给答案，也不重讲整道题，而是执行固定闭环：

1. 只解释当前小台阶。
2. 用一个具体例子示范方法。
3. 立即换一道数字或情境略有变化的相似题。
4. 明确告诉孩子本轮只需要回答什么。
5. 检查题答对才回到原学习路径；没听清、答非所问和答错分别处理。

## 教学转写规则

- 先实物、图示或动作，再说数量关系和计算方法。
- 每轮只保留一个认知动作，避免同时问多个问题。
- 讲解使用低年级口语，不使用“迁移”“模型”“策略”等成人术语。
- 原理必须落到“为什么这样做”，但一次不超过儿童可以听完的一小段。
- 检查题与示范题方法相同、数字或情境不同，不能原题原答案复读。
- 不复制公开课逐字稿，只吸收课程标准和教学设计中的方法原则后重新编写。

## 工程边界

- `microstep-quality-profiles.js` 存放与课程 212 个小台阶直接对应的专属讲解、示范和讲后检查，优先级最高。
- `microstep-explanation-library.js` 存放各类知识的通用讲法、示例和近迁移检查题。
- 课程中的专用 `teacherHint` 负责正常教学提示；它必须是实质讲解，不能只有“再想想”。
- 状态机负责区分答错、没听清、答非所问和请求帮助，只有答错才进入讲解与再检测。
- 图示必须使用讲解后的检查题上下文，不能继续展示上一轮题目。
- `microstep-explanation-audit.js` 逐项检查 212 个小台阶是否命中专属讲解，并检查文字长度、回答目标、答案泄露和知识边界。
