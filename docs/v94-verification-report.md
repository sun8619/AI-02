# v94 多答案题卡关修复

版本：`v94-20260831`。本报告记录可重复的工程验收，不把测试通过率当作儿童学习效果评分。

## 复现与根因

截图对应 `G1V2-U5-KP01-V03`：原题是 `1元=____角=____分。`，标准答案为 `10，100`。

1. `childFacingPrompt` 先匹配单空换算，左侧匹配又允许含等号，误吞了第一个空，输出 `1元=____角等于多少分？`。
2. 整题图示计划没有绑定整题的回答约定，回退到小步话术时又加上“这次只说几分”，与两个答案矛盾。
3. 语音相关性筛选把“100分”等部分答案拦在判题前；键盘虽然会追问，但不保存已答部分。正确的完整口语也可能因包含题目中的“1元”而被旧数字序列比较拒绝。
4. 旧回归主要把题库的标准答案字符串直接提交，覆盖不了孩子分次作答和自然口语的这条路径。

## 同类排查及修复

- 扫描当前全部42个知识点、462道题，找到57道多答案题：44道多空题，另有13道统计、分类和有余数应用题。
- 从当前题目生成带单位、数位、类别或答案角色的回答结构。语音和键盘使用同一结构，不通过正确答案反推或篡改孩子听写中的数字。
- 完整回答直接判题；部分回答保存为当前题的临时草稿，只问尚未回答的一部分。不加掌握证据，不把补答当作算错。
- 支持“十角一百分”“一元等于十角等于一百分”和带明确单位的反向回答；也支持数位描述、完整分合算式、乘法算式与结果、商和余数、统计类别与数量、质量换算的常见表达。
- 数值、单位、否定和冲突回答仍然校验；明确错误的完整回答仍进入讲解。不能只答其中一项就获得整题通过。
- 换题、重开题、切换知识点、进入错误讲解时清理草稿；草稿不落盘。
- 原题始终保留，当前问句与图下提示跟随缺失答案。双单位图同时标出“几角、几分”，不提前展示正确答案。
- 更新浏览器脚本缓存版本及发布文件哈希。

## 验收边界

本轮解决多答案题的明确问法、输入接受和补答死循环，不代表全站教学质量已完美。自动语音测试输入的是转写文本，不能证明真实儿童发音、噪声、设备权限和线上供应商链路的识别率。浏览器自动回归屏蔽收费语音接口；本地交互检查时曾看到语音服务不可用提示，没有把文字测试算作音频服务验证。服务器仍需按固定提交更新，并用真实麦克风复测。

上线后重点验收：进入这道1元双单位题，先说“100分”，应只追问“1元是几角”；再说“十角”，应进入下一题或本次通过。错误说成“九角”，则应进入讲解，不能直接通过。
