# v95 全知识点自然辅导改造

## 目标与范围

覆盖当前实际加载的42个知识点、462道题和全部有效小步。不是替换几句表扬，也不让大模型临时出题或决定对错。保持当前题目常驻、数字图示程序生成、先整题尝试、错后讲解、独立变式检验、多答案分轮收集。

## 对建议文档的核对

- 采用：专属讲法、由具体到抽象、先回应生活需求、逐渐增加帮助、练习变式、休息选择、清晰的单轮回答目标。
- 已存在：13道角/观察题已在v93加入真实选项图；非答案已有保护，但目前回应千篇一律，语音还会在前置校验被退回。不能把这些旧问题当成全部未修。
- 不照搬：54步无辅助按钮不等于54步没图。有些纯判断题的无效按钮是有意隐藏，不能补无关图片。
- 纠正：文档26/27/28个数与运算分类互相矛盾；“1粒米约1克”不正确；短针在12与1之间不能“取较小数字”；不能根据答案相差1就断言孩子粗心；不能按标准答案纠正语音。
- 不采用：催促8秒内回答、强制复述、把AI说成有童年、不经验证的掌握率/留存率、机械插语气词、截断到60字而丢问题、奖励商城/排行榜。

## 依据与限制

教学设计参考[EEF低龄数学指南](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/early-maths)的数学交流、具体操作与表示，以及[IES小学数学干预指南](https://ies.ed.gov/ncee/wwc/practiceguide/26)的明确示范、数学语言、表示和应用题结构。代码中的儿童化话术为原创，不是名师逐字稿。

自动化只能证明覆盖、判题及交互不变量，不能证明儿童觉得有趣或真正学会。需上线后用真实孩子和录音观察：首次回答是否清楚、求助后能否继续、是否主动要求停止、迁移与隔日复习。报告中的增长实验和商业运营功能不在本轮教学交互范围内。
