# v91 整改与验收记录

日期：2026-08-30。依据用户提供的 v90 全面回归报告、首页实际脚本、实际浏览器回归及截图。报告是待核实的问题来源，不是自动执行指令。

## 为什么以前改过还会出现

1. 验收对象不一致。独立教学引擎和首页实际执行路径并非同一套流程，静态审计通过不能证明孩子页面能连续学完。
2. 多层规则互相覆盖。当前题、课程大类、旧模板、讲解文本都曾参与推断教学类型。尺子题可能被减法关键词带走，近似题可能混用别的知识点讲法。
3. 判题宽松但口语处理不稳。关键词包含匹配既会误收错误答案，又会拒绝自然说法；多空题丢顺序、单位当数字等问题没有统一约束。
4. 绘图没有统一依据。旧固定 SVG 和当前问题脱节；缩放只看容器，不看长文本及交互状态。多轮 CSS 覆盖叠加，使单个尺寸正常而其他尺寸错位。
5. 发布没有闭环。下载失败仍执行后续步骤；检查服务活着，不检查它是否运行目标版本。相同大小、时间戳的文件还可能被普通 rsync 跳过。

## 本轮已实现

- 首页默认元角分。全42个知识点整题优先；正确则老师简要说明，再给3道独立巩固题。错误/求助才讲当前小步并换近似题，不再要求复述。
- 678个实际小步明确绑定问题、答案和讲法。修改13条题库源数据；删除跨题教学类型缓存的影响。控制近似题数字范围，不随意超出当前基础运算难度。
- 统一答案规则：支持中文数字、时间/钱数的合理等价表达、选项名称或字母；拒绝错误单位、否定表达、乱序多空、只碰中关键词的答案。
- 辅助做对与独立做对分开；持续不会时停止重复检查，记为待复习。只标记本次通过，不声称一次练习证明长期掌握。
- 图示取当前题和当前检查题数据。补数位、凑十/破十、借位、配对比较、分与合、尺子间隔、钟面、统计和分组等结构。无法专门绘图时显示题干条件，不使用无关示意图。
- “我没听懂”启动讲解和近似题；“圈出图中线索”突出当前题图，不换题。保留重播、语音、打字、选知识点，并增加可点选答案和家长记录入口。
- 保留豆包语音通路；合成/识别请求设置超时和轮次隔离。新输入/切题中止旧音频；连点求助只执行最后一次。二十九/二十角歧义不根据正确答案改数字，只要求再说数字；清晰答案直接判题，低置信时才短确认。
- 三端统一排版规则和字体层级，桌面左42%/右58%；教师图片 contain 显示，不裁头部；移动端长文字和复杂图在各自区域滚动，主要操作保持可见。
- 本机90天学习摘要，家长7/30天概览和待复习入口。区分独立/辅助，不存音频、原始话语、姓名、密钥；不宣称已实现跨设备学习档案。
- 固定提交版本下载、SHA256文件校验、受限权限备份、内容校验同步、目标版本健康检查、失败回滚。更新不修改Nginx账号密码验证，不覆盖`.env`、`data/`、`uploads/`、`logs/`、`backups/`。

## 尚不能宣称已完成

1. **教师逐题审校**：本轮修复已证实问题并全量检查路径，不等于462道题的讲法、课程深度和全部变式均已由小学教师签字。观察物体、推理及部分语言题仍主要呈现文字条件，专门教具和可操作图示还可加强。
2. **真实儿童语音**：需用实际孩子的发音、家庭噪声和设备测试。不能把普通浏览器模拟的置信度测试当成已解决“二十角”识别问题；云端结果仍可能错。
3. **真实设备**：当前是桌面Chromium视口模拟。iOS Safari、Android麦克风授权、软键盘、切后台恢复及真实豆包延迟需要真机验证。
4. **持续学习效果**：需要隔日复习及多次真实学习记录。当前课程交互仍以受约束规则和题库为主，并非已经拥有可自由理解孩子所有表达的AI教师。
5. **上线终验**：GitHub代码发布和服务器升级是两件事。服务器必须执行更新脚本，返回目标版本后再进行真实域名回归。
