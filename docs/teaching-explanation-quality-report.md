# 乐之老师全课程讲解质量检查报告

检查日期：2026-08-25

## 检查范围

- 人教版小学一、二年级数学核心知识点：42 个。
- 课程题目：462 道，其中应用题 100 道。
- 课程小台阶：212 个。
- 小台阶专属讲解：130 套。
- 覆盖的知识类型：数与运算、数量关系、图形、测量、时间、人民币、统计、推理等 30 类。

## 质量标准

每个小台阶的答错讲解必须同时满足：

1. 只讲孩子当前卡住的一件事，不重讲整题。
2. 先说明方法或道理，再给一个具体示范。
3. 示范后换数字或情境，用同一种方法检查是否听懂。
4. 明确告诉孩子本轮要回答数字、单位、算式、选择还是一句原因。
5. 讲解和检查题不提前泄露答案。
6. 不混入其他知识点的单位、情境、图示或术语。
7. 使用低年级口语，避免空泛地说“再想想”“认真看”。
8. 单轮长度适合语音播放：讲解不超过 80 字，示范不超过 50 字，检查题不超过 35 字。

## 本轮发现的主要问题

旧的讲解机制按关键词优先匹配通用模板。它能保证“有讲解”，但不能保证“讲对当前小步”。全量对照后发现的典型风险包括：

- 长度换算可能落入人民币换算话术。
- 平面图形、立体图形和角的讲解可能互相串用。
- “说清为什么”讲完后，检查题却只让孩子报数字。
- 凑十法、破十法的中间步骤和讲后检查目标不完全一致。
- 时间、统计、数位、搭配、余数应用等知识容易被过宽的通用规则覆盖。
- “能或不能”“可以或不可以”这类二选一回答会被误判成泄露答案。

## 已完成修复

- 新增 `microstep-quality-profiles.js`，为 212 个课程小台阶建立高优先级专属讲解层。
- 当前 212 个小台阶全部命中专属讲解，不再依赖旧通用模板兜底。
- 130 套讲解分别绑定讲解、示范、同目标再测题、答案关键词和回答指令。
- 轴对称、平移和旋转已从图形认识中拆成独立运动类，观察运动、判断名称、说明理由分别使用对应讲解和再测题。
- “说清原因”类小步改为检查理由或方法，不再跳回只报数字。
- 修正长度、重量、人民币、角、立体图形、统计、混合运算、搭配等知识家族的边界。
- 增加防回退审计：专属讲解少于 100 套、出现空泛提醒、文字过长、答案泄露或跨知识点污染时，自动检查会失败。

## 自动检查结果

- 42 个知识点均有专属教学路径。
- 42 个知识点均覆盖答对推进、答错讲解、不会答示范、跑题拉回、变式练习、老师归纳和整题检验。
- 212 个小台阶全部通过讲解与同目标再测检查。
- 462 道题全部通过知识类型污染检查。
- 页面提问清楚度、图示同步、防泄题和知识边界检查均通过。

## 仍需真人验证

自动检查可以发现结构、文字和知识边界问题，但不能替代真实儿童试用。上线前仍需至少完成：

- 每个知识家族选 2 至 3 名一年级或二年级儿童试学。
- 记录孩子第一次听懂率、请求提示次数、答非所问次数和语音识别误差。
- 观察孩子是否能在 2 至 3 道变式题后独立作答，而不是记住示范答案。
- 由小学数学教师抽查高风险知识：凑十法、破十法、数量关系、人民币、时间、余数应用和混合运算。
