# v95 全知识点自然辅导与措辞调整

版本：`v95-20260901`。本轮覆盖实际加载的42个知识点，不把自动测试计数当作学习效果评分。

## 改动依据

对照用户提供的两份建议文档，采用具体操作、不同讲法、先回应孩子、渐进帮助、变式和休息选择。没有照搬建议中的不准确例子、强制跟读、时间催促或奖励商城。详见 `docs/v95-coaching-plan.md`。

## 实际改变

1. 每个知识点有专属开场、操作线索、后续讲法、检查方法和生活意义。进一步按当前题的细分技能选择讲法，避免“同属一个知识点”就套同一句。
2. 第一题与后续练习都先给完整问题。答错或求助后，才讲当前卡住的小步，再问一道检查题。取消儿童必须复述老师原话的要求，保留v94的多答案分次补答。
3. 讲解明确区分“刚才这一问的示范”与“现在这道检查题”。使用本题数字和条件讲凑十、破十、逆运算、配对、分组、数位、单位换算、钟面和表格。最多三轮讲解后仍需帮助时，不再重复追问，提供休息或换题。
4. 讲完角的大小继续看另一种角；观察方向继续看另一视图；图形规律与数字规律分开；搭配与两位数排列分开。修复旧逻辑把“文字题干相同但图不同”的题也过滤掉的问题。
5. 独立答对后优先更换表示方式，求助/主动换题时优先选择较简单的同知识点题。按题型、数字规模和答案结构做可审计的排序，不宣称已实现经校准的个性化难度模型。不重复本轮已出题，每轮题量仍有上限；帮助完成不算独立掌握。
6. 喝水、累了、暂停、回来、无聊、问老师是谁、问学习用途等，有不同的明确回应。暂停保留题目与多答案草稿、排除休息时长；不自动倒计时催孩子。键盘与较清楚的语音转写都能进入这些路径，非数学交流不计数学错误。
7. 措辞修正包括：小数量比较不讲“最高位”；十位不提前堆入百位千位；形状问“什么图形”、位置问“谁/哪个面”，不统统替成“多少”；调查票数不说成水果个数；小步答对不误说整题已经完成。不随意加语气词，不贴“粗心”等标签。
8. 长条件题的题干完整保留，图下只提取明确的最终问题，减少重复；修正小屏长内容居中后从半句话开始显示的问题。小屏和键盘打开时，长题仍允许区域内滚动，不靠缩到小字或截掉条件伪装“一屏完整”。

## 验收边界

- 目前42点的核心教学状态、问题和判题由可审计的课程规则执行，不能把话术变化宣传成自由对话大模型已经接管教学。
- 自动语音测试提交的是转写文本，不是儿童真实录音。浏览器回归屏蔽付费接口，没有以文字测试冒充豆包ASR/TTS线上效果验收。
- 本轮没有验证实际7岁孩子的兴趣、理解速度、疲劳与隔日迁移，不宣称商业化或教学质量达到100%。仍需家长陪同真实使用观察，尤其是不清晰发音与长条件题。
- 建议上线抽测：元角分、破十减、图形规律、角分类、简单推理；各测试一次答对、答错、连续不会、休息返回及独立变式。

本轮工程与回归已完成。发布提交和服务器更新步骤见 `docs/v95-server-update.md`；线上版本以健康接口为准。
