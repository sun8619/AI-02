# 公开儿童服务验收门禁

当前自动化测试只能证明程序按既定规则运行，不能代替教师签审、真实儿童试用或真机验收。

## 数据最小化

- 所有儿童使用匿名编号，不填写姓名、学校、手机号或家庭住址。
- 录音只用于本次已获家长同意的识别评测；本仓库只保存指标CSV，不提交原始录音。
- `consent_recorded=true` 表示线下已留存可核验的家长同意记录，仓库中不得写入同意书中的个人信息。

## 四类验收

1. `teacher-review.csv`：小学数学教师逐题检查答案、歧义、可接受表达、脚手架、图示和年龄适配。
2. `child-voice.csv`：至少100条匿名真实童声，覆盖安静/家庭噪声、口音、数字和单位歧义；记录准确率、误采纳、安全问题和延迟。
3. `device-matrix.csv`：至少覆盖 iOS Safari、Android Chrome、微信内浏览器，验证麦克风、录音、ASR、键盘兜底、后台恢复、TTS自动播放和布局。
4. `learning-retention.csv`：至少10名匿名儿童完成基线、即时、隔日和7日复测，家长只观察不提示。

## 使用命令

```bash
npm run audit:human
npm run audit:public-ready
```

- `audit:human` 生成客观报告，不阻断当前受密码保护的内部预览发布。
- `audit:public-ready` 是转为公开儿童服务前的严格门禁，任何缺项都会退出失败。

## 默认阈值

- 462道题全部由教师批准；
- 童声样本不少于100条，精确识别率≥97%，直接采用率≥90%，误判为正确和安全问题为0，ASR中位延迟<2秒；
- 三类关键真机全部通过；
- 儿童试用不少于10人，7日复测通过率≥80%，挫败退出率≤10%。

阈值用于产品发布决策，不构成医学、教育效果或法律结论。
