# 乐之老师教学引擎

这个目录放“稳定、可复用、低成本”的教学策略层。它和火山大模型的关系是：

- 服务器内置：知识依赖、教学状态机、检验题、错题映射、回溯记录。
- 大模型处理：理解孩子自由表达、换一种自然讲法、生成低年级话术、评估开放式费曼复述。

这样做的目的：常规流程不每次都问大模型，降低延迟和算力消耗；需要真实语言理解时再调用模型。

## 已落地结构

- `renjiao-grade1-2-outline.js`
  - 一年级上、一下、二上、二下数学目录骨架。
  - 用于后续按教材顺序扩展，不直接复制教材原文和插图。
- `knowledge-model.js`
  - 定义知识模块、知识点、知识原子、前置依赖、掌握维度。
- `pilot-curriculum.js`
  - 首批试点知识点：
    - 一年级上：9加几，凑十法。
    - 一年级下：人民币元角换算。
    - 二年级上：几个几和乘法意义。
- `state-machine.js`
  - 固定教学流程：轻诊断 -> 小台阶 -> 细拆或回溯 -> 闯关检验 -> 错题重讲 -> 费曼复述 -> 掌握。

## 当前试点闭环

每个试点知识点都包含：

- 2-6 个知识原子。
- 强前置依赖和弱前置依赖。
- 常见错因。
- 2 道直接题、2 道变式题、1 道说理题。
- 错题到知识原子的映射。
- 费曼复述的关键点。

## 后续扩展原则

1. 不把整章一次性塞给大模型。
2. 先把每个知识点拆成知识原子。
3. 每个知识原子必须有前置依赖和检验目标。
4. 先扩高频、易卡住的知识点，再补齐一年级和二年级全量。
5. 页面增强必须跟状态机走，不能只做前端切换。

## 大模型调用边界

优先不用模型：

- 当前在哪个状态。
- 是否超过连续卡住阈值。
- 该回溯哪个强前置。
- 检验题是否进入错题重讲。
- 家长端卡住链路记录。

需要模型：

- 孩子自然语言回答很开放，规则无法判断。
- 同一个知识原子需要换一种讲法。
- 费曼复述需要判断是否讲出因果。
- 生成自然、短句、适合低年级孩子听的话。
- 生成生活类比图片提示词。
